Bem-vindo ao MQ Test

Este espaço reúne informações, conteúdos e atividades relacionadas ao universo da tecnologia e do desenvolvimento web.

O desenvolvimento de páginas envolve conceitos importantes, desde a estrutura do conteúdo até cores, fontes, espaçamentos e organização visual.

Uma página moderna também precisa funcionar corretamente em diferentes tamanhos de tela, tornando a responsividade fundamental.

Estudos

O aprendizado de desenvolvimento web pode ser dividido em diferentes áreas. HTML organiza o conteúdo e CSS define sua apresentação.

Recursos como Flexbox, Grid, posicionamento e Media Queries ajudam a criar layouts adaptáveis para diferentes dispositivos.

JavaScript acrescenta comportamento e interatividade às páginas, respondendo às ações do usuário.

Testes

Esta seção pode ser utilizada para testar o funcionamento e a aparência da página em diferentes resoluções.

As Media Queries permitem modificar fontes, margens, espaçamentos, menus e outros elementos de acordo com o dispositivo.

Exercícios

A realização de exercícios permite colocar em prática os conceitos estudados e identificar quais assuntos precisam de maior atenção.

Exercício: teste diferentes tamanhos de fonte, margens, espaçamentos e larguras para observar o comportamento do layout.
